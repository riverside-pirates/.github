# Ahoy from Riverside Pirates 🏴‍☠️

Computer Science and Engineering at [Riverside High School](https://www.dpsnc.net/o/riverside)
in Durham, NC. We teach [PLTW](https://www.pltw.org) Computer Science Essentials, and this
GitHub organization is where the class does its work.

This is the public front door. Most repos here are private on purpose: they hold student
work and grading. A link that says "404" is one of those.

## I'm a student

> [!IMPORTANT]
> You can't join on your own. Your teacher adds you from the class roster, and GitHub emails
> you an invitation to **riverside-pirates**. Accept it, and every link below works.

1. **Accept the invitation** in your school email. Check spam if it's missing.
2. **Sign in** at the course page,
   [classroom50.org/riverside-pirates/computer-science-essentials](https://classroom50.org/riverside-pirates/computer-science-essentials).
   Assignments and scores live there.
3. **Accept an assignment**, open your repository, and create a codespace. The
   [Codespaces guide](https://github.com/riverside-pirates/computer-science/blob/main/guides/codespaces.md)
   walks you through it.

| You need | Go to |
| --- | --- |
| Course readings and PLTW activities | [my.pltw.org](https://my.pltw.org) |
| Riverside links: Canvas, schedules, handbook | [Riverside Quick Links](https://www.dpsnc.net/o/riverside/page/quick-links) |
| Help with your codespace, Git, or Python | [Student guides](https://github.com/riverside-pirates/computer-science): setup, Codespaces, troubleshooting, blocks to Python, glossary |

## I'm a parent or guardian

Students write real programs in a browser-based editor, save their work with Git, and get
feedback from automated tests every time they save. These are the same tools professional
developers use.

Student work stays private. This organization never publishes student names, usernames, or
grades.

The [Riverside Engineering Parent Action Council (REPAC)](https://github.com/riverside-pirates/repac)
supports the PLTW program. Start there to get involved.

## I'm a teacher

Everything public here is yours to reuse: the
[student guides](https://github.com/riverside-pirates/computer-science), the one-template-repo-per-assignment
pattern, and pytest autograding through [Classroom 50](https://classroom50.org). Want to know
how it's set up? [Open an issue](https://github.com/riverside-pirates/.github/issues/new).

## Want to help?

We're a cyber-assisted learning crew, and we welcome partners.

- **Guest speakers.** Work in tech, engineering, or anything built with code? Students want to
  hear about it. [Open an issue](https://github.com/riverside-pirates/.github/issues/new).
- **Contributors.** Fix a typo in a guide, review a pull request, or claim a bounty on the
  [Shipyard](https://github.com/riverside-pirates/shipyard).
  [Open an issue](https://github.com/riverside-pirates/.github/issues/new).
- **Cloud sponsors.** Every student codes on a GitHub Codespace, and those hours cost money.
  [Open an issue](https://github.com/riverside-pirates/.github/issues/new).
